# Conventions and mapping to the tutorial

- c(T P^k) = (1 + x)^{k+1} with x the hyperplane class (eq. (10)); the tutorial uses the same for CP^m (exm-spd-cp2-not-spin) and
  the analogous formula for hypersurfaces.
- Signature theorem tau = (1/3) int (c_1^2 - 2 c_2) = -(2/3) chi = -16 for K3 (eq. (20)); the tutorial uses p_1 = 3 tau and
  A-hat = -p_1/24.
- The spinor decomposition (89) is written 16 -> (4,2,1) + (4,1,2) without marking six-dimensional chirality; the tutorial
  writes (4,2,1) + (4',1,2) following prp-spinor-branching.
