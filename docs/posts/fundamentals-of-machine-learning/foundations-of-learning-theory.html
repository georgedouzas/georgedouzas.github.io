Foundations of Learning Theory

This chapter delves into the theoretical underpinnings of machine learning, providing a formal basis for understanding how algorithms can learn from data. We explore both statistical learning theory—which focuses on the fundamental relationship between models, data, and prediction—and computational learning theory—which addresses the algorithmic and complexity aspects of learning. Together, these frameworks provide the mathematical foundations that allow us to reason about the reliability, efficiency, and limitations of machine learning models.

Statistical Learning Theory

Statistical learning theory provides the foundational framework for understanding how to estimate an unknown function from data and make predictions on new observations. This section covers the core concepts from statistical learning, including the fundamental model, the prediction-inference tradeoff, parametric versus non-parametric methods, and the critical bias-variance decomposition.

For more on this topic, see Bishop and Bishop (2024, Ch. 4), James et al. (2023, Ch. 2), Shalev-Shwartz and Ben-David (2014, Chs. 2, 3, 4, 5, 6, 7, 8) and Theodoridis (2026, Ch. 12).

The Statistical Learning Framework

At the heart of statistical learning is a simple but powerful model. Suppose we observe a quantitative response Y and p different predictors X_1, X_2, \ldots, X_p. We assume there exists a relationship between Y and \mathbf{X} = (X_1, X_2, \ldots, X_p) that can be written as:

Y = f(\mathbf{X}) + \epsilon

where:

  • f is some fixed but unknown function representing the systematic information that \mathbf{X} provides about Y
  • \epsilon is a random error term that is independent of \mathbf{X} and has mean zero: \mathbb{E}[\epsilon] = 0

The error term captures unmeasured variables, unmeasurable variation, and measurement error.

Why Estimate f: Prediction and Inference

There are two primary reasons for estimating f: prediction and inference.

Prediction

In many situations, inputs \mathbf{X} are readily available, but the output Y cannot be easily obtained. Since \mathbb{E}[\epsilon] = 0, we can predict Y using \hat{Y} = \hat{f}(\mathbf{X}) where \hat{f} represents our estimate for f. In prediction settings, \hat{f} is often treated as a black box.

The accuracy of \hat{Y} depends on two types of error. For a given estimate \hat{f} and predictors \mathbf{X}:

\mathbb{E}[(Y - \hat{Y})^2] = [f(\mathbf{X}) - \hat{f}(\mathbf{X})]^2 + \text{Var}(\epsilon)

The first term is reducible error (can be improved with better methods), and the second is irreducible error (cannot be reduced). The irreducible error provides a lower bound on prediction accuracy.

Inference

In inference problems, we want to understand the relationship between Y and \mathbf{X}. Key questions include: Which predictors are associated with the response? What is the relationship between the response and each predictor? Can the relationship be adequately summarized using a linear equation?

Parametric vs Non-Parametric Methods

Parametric Methods involve two steps: Make an assumption about the functional form of f (e.g., linear) and use training data to fit the model. This reduces the problem to estimating a set of parameters. Advantages include simplicity and interpretability. Disadvantages include potential model misspecification and overfitting with flexible models.

Non-Parametric Methods do not make explicit assumptions about the functional form of f. They seek an estimate that gets close to data points without being too rough. Advantages include avoiding functional form assumptions and fitting wider range of shapes. Disadvantages include requiring very large datasets and potential overfitting.

The Flexibility-Interpretability Tradeoff

Methods vary in flexibility (range of shapes they can generate). Less flexible methods (linear regression, logistic regression) are more interpretable. More flexible methods (GAMs, trees, neural networks, boosting) are less interpretable. As flexibility increases, interpretability generally decreases. Surprisingly, more flexible methods don’t always predict better due to overfitting.

Supervised vs Unsupervised Learning

Supervised Learning

For each observation of predictors \mathbf{x}_i, there is an associated response y_i. Goal is to fit a model relating response to predictors. Examples include linear regression (see Linear Models), logistic regression, SVMs (see Margin Methods), and neural networks (see Neural Networks).

Unsupervised Learning

We observe predictors \mathbf{x}_i but no associated response y_i. Goal is to understand relationships between variables or observations. Examples include clustering (see Clustering) and PCA (see Dimensionality Reduction).

Assessing Model Accuracy

No single method dominates all others over all possible datasets. We must evaluate model performance on test data not used for training. For regression, the most common measure is mean squared error (MSE). For classification, common measures include error rate and accuracy. We want to choose the method that gives the lowest test error, not training error.

Computational Learning Theory

Computational learning theory provides a formal framework for studying the problem of induction—that is, of generalizing from a finite set of examples to a broader context. The central goal is to understand the conditions under which a learning algorithm can be expected to perform well on unseen data, and to provide guarantees on that performance.

PAC Learning Framework

The Probably Approximately Correct (PAC) learning framework provides a formal model for understanding when and how learning is possible. This computational perspective complements the statistical view presented above.

The No-Free-Lunch Theorem

Before delving into the models of learnability, it is crucial to understand a fundamental limitation of machine learning, articulated by the No-Free-Lunch (NFL) theorem. The NFL theorem states that for any learning algorithm, there is no single best model that works for all possible data distributions. For any learner, there exists a data distribution for which it will perform no better than random guessing.

Theorem 1 Let A be any learning algorithm for the task of binary classification. Let the domain \mathcal{X} be a set of size 2n. Then there exists a distribution \mathcal{D} over \mathcal{X} \times \{0,1\} such that:

  • There exists a function f: \mathcal{X} \rightarrow \{0,1\} with L_{\mathcal{D}}(f) = 0.
  • For a training set S of size n, sampled from \mathcal{D}, the expected true error of the hypothesis output by A is at least 1/4.

This theorem implies that there is no universally superior learning algorithm. The success of a machine learning algorithm depends on the assumptions it makes about the data, a concept known as inductive bias. Without such assumptions, we cannot hope to generalize from a finite training set (Shalev-Shwartz and Ben-David 2014).

The PAC (Probably Approximately Correct) model formalizes the learning problem computationally. The basic setup consists of the following components (Shalev-Shwartz and Ben-David 2014):

Definition 1  

  • Domain Set (\mathcal{X}): An arbitrary set of objects that we wish to label.
  • Label Set (\mathcal{Y}): The set of possible labels (e.g., \{0, 1\}).
  • Training Data (S): A finite sequence of labeled examples, S = ((x_1, y_1), \dots, (x_m, y_m)), sampled i.i.d. from an unknown probability distribution \mathcal{D} over \mathcal{X} \times \mathcal{Y}.
  • Hypothesis Class (\mathcal{H}): A set of functions h: \mathcal{X} \rightarrow \mathcal{Y} that the learning algorithm can choose from. This is the inductive bias of the learner.

The learner’s output is a hypothesis h \in \mathcal{H}. The goal is to find a hypothesis with low true error (or risk), defined for the 0-1 loss as:

Definition 2 True Error (Risk)

The true error (risk) of hypothesis h under distribution \mathcal{D}:

L_{\mathcal{D}}(h) = \mathbb{P}_{(x,y) \sim \mathcal{D}}[h(x) \neq y]

Since \mathcal{D} is unknown, the learner uses the empirical error on the training set S as a proxy:

Definition 3 Empirical Error

L_S(h) = \frac{1}{m} |\{i \in [m] : h(x_i) \neq y_i\}|

Probably Approximately Correct (PAC) Learning

The PAC learning framework answers a fundamental question: how many training examples do we need to learn a good hypothesis with high confidence? The framework provides finite-sample guarantees rather than asymptotic results, making it directly applicable to practical machine learning.

The PAC model formalizes learning under the realizability assumption: there exists at least one hypothesis h^* \in \mathcal{H} with zero true error, L_{\mathcal{D}}(h^*) = 0. This means our hypothesis class contains the “true” function generating the data—an idealized but useful starting point.

Definition 4 PAC Learnable

A hypothesis class \mathcal{H} is PAC learnable if there exists a function m_{\mathcal{H}}:(0,1)^2 \rightarrow \mathbb{N} and a learning algorithm such that for every \epsilon, \delta \in (0,1) and distribution \mathcal{D} (under realizability), running the algorithm on m \ge m_{\mathcal{H}}(\epsilon, \delta) i.i.d. examples returns h with:

\mathbb{P}[L_{\mathcal{D}}(h) \le \epsilon] \ge 1-\delta

Let’s unpack this definition. The parameters \epsilon and \delta represent our learning goals: - \epsilon is the accuracy parameter: we want a hypothesis with error at most \epsilon - \delta is the confidence parameter: we want this guarantee to hold with probability at least 1-\delta

The function m_{\mathcal{H}}(\epsilon, \delta) is the sample complexity: it tells us how many examples we need. For example, if we want 95% confidence (\delta = 0.05) that our error is at most 1% (\epsilon = 0.01), the sample complexity tells us the required training set size.

For a finite hypothesis class \mathcal{H}, the Empirical Risk Minimization (ERM) algorithm is a successful PAC learner. The sample complexity is bounded as:

m_{\mathcal{H}}(\epsilon, \delta) \le \left\lceil \frac{\ln(|\mathcal{H}|/\delta)}{\epsilon} \right\rceil

This elegant result shows that the sample complexity grows logarithmically with the hypothesis class size and linearly with 1/\epsilon. For instance, if |\mathcal{H}| = 1000, \epsilon = 0.1, and \delta = 0.05, we need approximately \lceil \frac{\ln(20000)}{0.1} \rceil \approx 100 examples. Doubling the accuracy requirement (halving \epsilon) doubles the sample requirement, while increasing the hypothesis class size by a factor of 1000 only adds about 70 examples due to the logarithmic dependence.

Agnostic PAC Learning

The realizability assumption is often unrealistic—real data contains noise, and our hypothesis class may not contain the true function. The agnostic PAC model addresses this by dropping the realizability assumption. Instead of seeking zero error, we aim to compete with the best hypothesis in our class.

Definition (Agnostic PAC Learnability): A hypothesis class \mathcal{H} is agnostically PAC learnable if there exists a function m_{\mathcal{H}}:(0,1)^2 \rightarrow \mathbb{N} and a learning algorithm such that for every \epsilon, \delta \in (0,1) and for every distribution \mathcal{D}, running the algorithm on m \ge m_{\mathcal{H}}(\epsilon, \delta) i.i.d. examples returns a hypothesis h such that, with probability at least 1-\delta:

Definition 5 Agnostic PAC Learning

A hypothesis class \mathcal{H} is agnostic PAC learnable if for every \epsilon, \delta \in (0,1) and distribution \mathcal{D}, with probability at least 1-\delta:

L_{\mathcal{D}}(h) \le \min_{h^* \in \mathcal{H}} L_{\mathcal{D}}(h^*) + \epsilon

This guarantee is weaker but more realistic: we only promise to be within \epsilon of the best possible hypothesis in our class. If the best hypothesis has 10% error, we guarantee at most 11% error (with \epsilon = 0.01).

In the agnostic setting, the sample complexity depends on a more sophisticated measure of complexity than just the size of \mathcal{H}. This is captured by the Vapnik-Chervonenkis (VC) dimension, denoted \text{VCdim}(\mathcal{H}). The sample complexity for any class \mathcal{H} with finite VC-dimension is:

m_{\mathcal{H}}(\epsilon, \delta) = O\left( \frac{\text{VCdim}(\mathcal{H}) + \ln(1/\delta)}{\epsilon^2} \right)

Note the crucial difference: sample complexity now scales as 1/\epsilon^2 rather than 1/\epsilon. This quadratic dependence means that achieving high accuracy in the agnostic setting is significantly more expensive. To halve the error, we need four times as many examples. This fundamental result connects the generalization ability of a learner to the complexity of its hypothesis class (Shalev-Shwartz and Ben-David 2014; Theodoridis 2026).

The VC-Dimension

Definition

The VC-dimension is a combinatorial measure that captures the expressiveness of a hypothesis class. Unlike simply counting hypotheses, it measures the ability to realize different labelings of data points.

Definition (Shattering): A hypothesis class \mathcal{H} shatters a finite set C \subseteq \mathcal{X} if for every possible labeling of the points in C, there exists a hypothesis in \mathcal{H} that realizes that labeling.

For example, consider three points on a line and the class of threshold functions h_a(x) = \mathbb{1}_{x \geq a}. Can we shatter these three points? We need to realize all 2^3 = 8 possible labelings. Try as we might, we cannot: if the middle point is labeled 1 and the two outer points are labeled 0, no threshold can achieve this. Therefore, threshold functions cannot shatter three points.

Definition 6 VC-Dimension

The VC-dimension of \mathcal{H} is the maximum size of a set that can be shattered:

\text{VCdim}(\mathcal{H}) = \max\{ |C| : C \text{ is shattered by } \mathcal{H} \}

size of the largest set that can be shattered by \mathcal{H}.

Examples and Geometric Intuition

Examples with geometric intuition:

  • Threshold functions on \mathbb{R}: \text{VCdim} = 1. We can shatter any single point (two labelings: 0 or 1), but not two points (cannot achieve [1,0] labeling).

  • Intervals on \mathbb{R}: \text{VCdim} = 2. An interval [a,b] can shatter two points but not three. For three points x_1 < x_2 < x_3, we cannot achieve the labeling [1,0,1] with a single interval.

  • Linear classifiers in \mathbb{R}^d: \text{VCdim} = d + 1. A hyperplane in d dimensions can shatter d+1 points in general position. For \mathbb{R}^2, three points can be shattered (try all 8 labelings with different line orientations), but four points in general position cannot all be shattered.

Fundamental Theorem of Statistical Learning: A hypothesis class \mathcal{H} is PAC learnable if and only if it has finite VC-dimension.

This theorem is remarkable: it provides a complete characterization of learnability. A class is learnable precisely when its VC-dimension is finite, regardless of the specific learning algorithm used.

Sauer’s Lemma and Growth Functions

Sauer’s Lemma provides a crucial bound on the effective size of a hypothesis class when restricted to a finite sample.

Sauer’s Lemma: If \text{VCdim}(\mathcal{H}) = d, then for any set of m points, the number of different labelings that can be realized by \mathcal{H} is at most \sum_{i=0}^d \binom{m}{i}.

For m > d, this bound is approximately (em/d)^d, showing that the effective size of \mathcal{H} grows polynomially rather than exponentially with the sample size. This polynomial growth is what makes learning possible—if the effective size grew exponentially, we would need exponentially many examples to learn. The technical details of this bound are provided in Technical Lemmas.

Generalization, Complexity, and Stability

Understanding generalization is the central challenge of learning theory. We want to find a hypothesis h that not only performs well on the training data S, but also on unseen data from the distribution \mathcal{D}. This section explores the key concepts that govern generalization.

For more on this topic, see James et al. (2023, Ch. 6).

The Generalization Gap

Definition 7 Generalization Gap

The generalization gap for hypothesis h:

L_{\mathcal{D}}(h) - L_S(h)

A key goal of learning theory is to bound this gap. A powerful tool for this is the concept of uniform convergence, which aims to bound the generalization gap for all hypotheses in a class simultaneously.

With probability at least 1-\delta, for all h \in \mathcal{H}:

|L_{\mathcal{D}}(h) - L_S(h)| \le \epsilon(m, \mathcal{H}, \delta)

If this holds, we can guarantee that the empirical risk minimizer, h_S = \text{ERM}_{\mathcal{H}}(S), will also have a small true error.

The Bias-Variance Trade-Off

The bias-variance trade-off is one of the most fundamental concepts in machine learning, explaining why both overly simple and overly complex models fail to generalize well. This decomposition, introduced in Probability and Statistics, provides deep insight into the nature of prediction errors.

For regression problems with squared loss, consider predicting a target y = f(x) + \epsilon, where f(x) is the true function and \epsilon is irreducible noise with \mathbb{E}[\epsilon] = 0 and \text{Var}(\epsilon) = \sigma^2. When we train a model \hat{f}(x) on a random training set, the expected squared error at a point x decomposes as:

\mathbb{E}[(y - \hat{f}(x))^2] = \underbrace{(\mathbb{E}[\hat{f}(x)] - f(x))^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}[(\hat{f}(x) - \mathbb{E}[\hat{f}(x)])^2]}_{\text{Variance}} + \underbrace{\sigma^2}_{\text{Irreducible Error}}

Let’s understand each component through a concrete example. Suppose the true relationship is f(x) = \sin(2\pi x) for x \in [0,1], and we observe noisy data y_i = f(x_i) + \epsilon_i.

Understanding Bias

Bias: The bias term (\mathbb{E}[\hat{f}(x)] - f(x))^2 measures how far the average prediction (averaged over all possible training sets) is from the truth.

Consider fitting a linear model \hat{f}(x) = ax + b to our sine function. No matter how much data we collect, a line cannot capture the oscillating pattern of a sine wave. The average linear fit will systematically miss the true function—this is high bias. The model is too simple; it underfits the data. Even with infinite data, the bias remains because the hypothesis class (linear functions) doesn’t contain the true function.

Understanding Variance

Variance: The variance term \mathbb{E}[(\hat{f}(x) - \mathbb{E}[\hat{f}(x)])^2] measures how much the predictions vary across different training sets.

Now consider fitting a 20th-degree polynomial to just 10 noisy data points. The polynomial can wiggle through all the points, but if we collect a new training set and fit again, we’ll get a completely different polynomial. The predictions at any given x will vary wildly—this is high variance. The model is too complex; it overfits by fitting the noise in the training data. With more data, the variance decreases because the model’s flexibility is constrained by more observations.

Irreducible Error: The term \sigma^2 represents the inherent noise in the data. Even if we knew the true function f(x) perfectly, we couldn’t predict better than this because of the random noise \epsilon. This sets a fundamental lower bound on prediction error.

The Trade-Off

The Trade-Off: The key insight is that bias and variance move in opposite directions as we change model complexity:

  • Simple models (e.g., linear): High bias (can’t capture complex patterns), low variance (stable predictions) - Complex models (e.g., high-degree polynomials): Low bias (can fit complex patterns), high variance (unstable predictions)

The optimal model complexity minimizes the sum of bias and variance. This is why regularization techniques (discussed in Linear Models and Margin Methods) are so important—they control model complexity to balance this trade-off.

Classification Error Rate

For classification problems, the decomposition is more subtle but the intuition remains: simple models make systematic errors (bias) but are stable, while complex models are flexible but unstable. The mathematical details differ, but the fundamental trade-off persists (James et al. 2023; Bishop and Bishop 2024). achievable error.

Increasing model complexity typically decreases bias but increases variance. The goal is to find a sweet spot that minimizes the total error (James et al. 2023; Bishop and Bishop 2024).

Measures of Complexity

To achieve uniform convergence, we need to measure the complexity, or “richness,” of the hypothesis class \mathcal{H}.

Vapnik-Chervonenkis (VC) Dimension

The VC-dimension is a combinatorial measure of complexity. It is defined as the size of the largest set of points that the hypothesis class can shatter.

Definition 8 Shattering

A set C \subseteq \mathcal{X} is shattered by \mathcal{H} if for every labeling of C, there exists h \in \mathcal{H} realizing it:

|\{ h \cap C : h \in \mathcal{H} \}| = 2^{|C|}

points in C, there exists a hypothesis in \mathcal{H} that realizes that labeling. That is, |{ h \cap C : h \in \mathcal{H} }| = 2^{|C|}.

  • VC-dimension: \text{VCdim}(\mathcal{H}) = \max\{ |C| : C \text{ is shattered by } \mathcal{H} \}. If \mathcal{H} can shatter arbitrarily large sets, its VC-dimension is infinite.

Examples

Example: The VC-dimension of half-intervals on the real line is 2. The VC-dimension of linear classifiers in \mathbb{R}^d is d+1.

The Fundamental Theorem of Statistical Learning states that a hypothesis class \mathcal{H} is agnostically PAC learnable if and only if it has a finite VC-dimension. The generalization bound is given by:

L_{\mathcal{D}}(h) \le L_S(h) + O\left(\sqrt{\frac{\text{VCdim}(\mathcal{H}) + \ln(1/\delta)}{m}}\right)

Rademacher complexity is a data-dependent measure of complexity that measures the ability of a hypothesis class to fit random noise.

Definition 9 The empirical Rademacher complexity of \mathcal{H} with respect to sample S:

\hat{\mathfrak{R}}_S(\mathcal{H}) = \mathbb{E}_{\boldsymbol{\sigma}}\left[ \sup_{h \in \mathcal{H}} \frac{1}{m} \sum_{i=1}^m \sigma_i h(x_i) \right]

where \sigma_i are independent Rademacher random variables with P(\sigma_i=\pm 1) = 1/2.

With probability at least 1-\delta, for all h \in \mathcal{H}:

L_{\mathcal{D}}(h) \le L_S(h) + 2\mathfrak{R}_m(\mathcal{H}) + \sqrt{\frac{\ln(1/\delta)}{2m}}

where \mathfrak{R}_m(\mathcal{H}) is the average empirical Rademacher complexity. This bound is often tighter than the VC-dimension bound because it adapts to the specific data distribution (Shalev-Shwartz and Ben-David 2014).

Algorithmic Stability

Stability is a property of a learning algorithm, rather than a hypothesis class. It measures how sensitive the algorithm’s output is to small changes in the training data. An algorithm is stable if replacing a single example in the training set does not significantly change the resulting hypothesis.

Definition (Uniform Stability): An algorithm A has uniform stability \beta with respect to a loss function \ell if for all datasets S, S' that differ by at most one example, and for all z \in \mathcal{X} \times \mathcal{Y}:

|\ell(A(S), z) - \ell(A(S'), z)| \le \beta

It can be shown that if an algorithm has uniform stability \beta, then the generalization gap is bounded:

|\mathbb{E}_S[L_S(A(S))] - L_{\mathcal{D}}(A(S))]| \le \beta

Regularization is a common technique for improving the stability of an algorithm. For example, Tikhonov regularization for SVMs can be shown to lead to a stable algorithm, which in turn guarantees good generalization (Shalev-Shwartz and Ben-David 2014; Theodoridis 2026).

Model Selection and Validation

Model selection is the process of selecting the best model from a set of candidate models. This includes choosing the right algorithm, the right hyperparameters, and the right set of features. Validation is the process of evaluating a trained model’s performance on unseen data.

For more on this topic, see Bishop and Bishop (2024, Ch. 12), James et al. (2023, Ch. 5) and Theodoridis (2026, Chs. 12, 13).

The Validation Set Approach

A simple approach to model selection is to split the available data into a training set and a validation set (or hold-out set). The model is trained on the training set, and the validation set is used to evaluate its performance and to tune hyperparameters. The model with the best performance on the validation set is then selected. While simple, this approach has the disadvantage that the performance estimate can be highly variable, depending on which observations are included in the training and validation sets.

Cross-Validation

Cross-validation is a more robust method for model selection and performance estimation. It involves partitioning the data into multiple subsets, or folds, and then training and evaluating the model multiple times.

k-Fold Cross-Validation

  • k-Fold Cross-Validation: The data is randomly divided into k equal-sized folds. For each fold, the model is trained on the remaining k-1 folds and evaluated on the held-out fold. The performance measure is then averaged across the k folds. This provides a more accurate estimate of the model’s performance on unseen data.

Leave-One-Out Cross-Validation

  • Leave-One-Out Cross-Validation (LOOCV): This is a special case of k-fold cross-validation where k is equal to the number of observations, n. In each iteration, the model is trained on n-1 observations and evaluated on the single held-out observation. LOOCV provides an almost unbiased estimate of the test error but can be computationally expensive (James et al. 2023; Shalev-Shwartz and Ben-David 2014).

The Bootstrap

Bootstrap Method

The bootstrap is a resampling method that can be used to estimate the uncertainty of a statistical estimate, such as a model parameter or a performance metric. It involves repeatedly drawing random samples with replacement from the original dataset and re-computing the estimate for each sample. The distribution of these bootstrap estimates can then be used to approximate the sampling distribution of the original estimate (James et al. 2023).

Information Criteria

Information criteria are methods for model selection that provide a trade-off between the goodness of fit of a model and its complexity.

AIC

  • Akaike Information Criterion (AIC): The AIC is defined as:

    \text{AIC} = 2k - 2\ln(\hat{L})

    where k is the number of parameters in the model and \hat{L} is the maximum value of the likelihood function for the model. The model with the lowest AIC is preferred.

BIC

  • Bayesian Information Criterion (BIC): The BIC is similar to the AIC but with a larger penalty for model complexity:

    \text{BIC} = k\ln(n) - 2\ln(\hat{L})

where n is the number of observations. The BIC tends to favor simpler models than the AIC (James et al. 2023).

Structural Risk Minimization (SRM)

The principle of Structural Risk Minimization (SRM) provides a formal framework for model selection based on the VC-dimension. It involves defining a nested sequence of hypothesis classes \mathcal{H}_1 \subset \mathcal{H}_2 \subset \dots with increasing VC-dimension. For each class, a bound on the generalization error is calculated. The SRM principle then chooses the hypothesis class that minimizes this bound, providing a balance between the empirical error and the complexity of the model (Shalev-Shwartz and Ben-David 2014).

Computational Complexity of Learning

While statistical learning theory addresses the question of how many examples are needed for learning, computational learning theory studies the computational resources required for learning. This section explores the computational aspects of learning, including the complexity of implementing the ERM rule and the hardness of learning certain concept classes.

Efficient Learning and the ERM Rule

A learning algorithm is considered efficient if its running time is polynomial in the relevant parameters: the sample size m, the dimension of the input space, 1/\epsilon, and 1/\delta. The question arises: when can the ERM rule be implemented efficiently?

Definition (Efficient ERM Implementation): A hypothesis class \mathcal{H} has an efficient ERM implementation if there exists a polynomial-time algorithm that, given a sample S, returns a hypothesis h \in \mathcal{H} that minimizes the empirical risk L_S(h).

For some hypothesis classes, implementing ERM is computationally tractable:

Tractable Cases

  • Linear predictors: Finding the ERM for linear regression can be solved in polynomial time using least squares. - Decision trees: While finding the optimal decision tree is NP-hard, practical heuristics like ID3 and C4.5 provide efficient approximate solutions. - Convex hypothesis classes: When the hypothesis class and loss function are convex, ERM reduces to convex optimization, which can be solved efficiently.

However, for many natural hypothesis classes, implementing ERM is computationally intractable:

Theorem (Hardness of ERM for Intersections of Halfspaces): Let \mathcal{H} be the class of intersections of k halfspaces in \mathbb{R}^d. Then, implementing ERM for \mathcal{H} is NP-hard for k \geq 2.

Cryptographic Hardness of Learning

Some concept classes are not only hard to learn information-theoretically but also computationally hard under cryptographic assumptions. The connection between learning and cryptography has led to important insights about the limits of efficient learning.

Definition (Cryptographically Hard Learning): A concept class \mathcal{C} is cryptographically hard to learn if learning \mathcal{C} efficiently would imply breaking a well-established cryptographic assumption (such as the hardness of factoring large integers or the discrete logarithm problem).

Example: The class of Boolean circuits of polynomial size is believed to be cryptographically hard to learn. This is because efficient learning of such circuits would imply the ability to invert one-way functions, which would break many cryptographic protocols.

The Relationship Between Proper and Improper Learning

In proper learning, the algorithm must output a hypothesis from the target class \mathcal{H}. In improper learning, the algorithm can output any hypothesis, as long as it achieves low error.

Theorem: There exist concept classes that are efficiently learnable improperly but not efficiently learnable properly (under cryptographic assumptions).

This separation shows that allowing the learner to use a richer hypothesis class can sometimes overcome computational barriers.

Hardness Results for Specific Problems

Several natural learning problems have been shown to be computationally hard:

  1. Learning DNF formulas: Learning disjunctive normal form (DNF) formulas is believed to be hard, though they can be learned improperly using polynomial-time algorithms.

  2. Learning neural networks: Training neural networks with even a single hidden layer is NP-hard in the worst case.

  3. Learning Gaussian mixture models: Efficiently learning the parameters of Gaussian mixture models is computationally challenging, even with mild separation assumptions.

Positive Results and Efficient Algorithms

Efficient Learnable Classes

Despite these hardness results, many important concept classes can be learned efficiently:

  1. Linear separators: The Perceptron algorithm efficiently learns linearly separable concepts.

  2. Decision lists: These can be learned efficiently using a greedy algorithm.

  3. Sparse polynomials: Polynomials with few terms can be learned efficiently using techniques from algebraic computation.

Nonuniform Learning and Structural Risk Minimization

While PAC learning requires uniform convergence over all distributions, there are weaker notions of learnability that allow for more flexibility. This section explores nonuniform learning and the Structural Risk Minimization (SRM) principle.

Nonuniform Learnability

Definition (Nonuniform Learnability): A hypothesis class \mathcal{H} is nonuniformly learnable if there exist a learning algorithm A and a function m_{\mathcal{H}}^{\text{NUL}}: (0,1)^2 \times \mathcal{H} \to \mathbb{N} such that for every \epsilon, \delta \in (0,1) and h \in \mathcal{H}, if m \geq m_{\mathcal{H}}^{\text{NUL}}(\epsilon, \delta, h), then for every distribution \mathcal{D}:

\mathbb{P}_{S \sim \mathcal{D}^m}[L_{\mathcal{D}}(A(S)) \leq L_{\mathcal{D}}(h) + \epsilon] \geq 1 - \delta

The key difference from PAC learning is that the sample complexity can depend on the specific hypothesis h being compared against.

Theorem (Characterization of Nonuniform Learnability): A hypothesis class \mathcal{H} is nonuniformly learnable if and only if it can be written as a countable union of PAC learnable classes: \mathcal{H} = \bigcup_{n=1}^\infty \mathcal{H}_n where each \mathcal{H}_n has finite VC-dimension.

Structural Risk Minimization

The SRM principle provides a systematic approach to model selection by balancing empirical risk and model complexity. Given a nested sequence of hypothesis classes: \mathcal{H}_1 \subseteq \mathcal{H}_2 \subseteq \cdots \subseteq \mathcal{H}

SRM selects the hypothesis that minimizes: \hat{h} = \arg\min_{h \in \bigcup_n \mathcal{H}_n} \left\{ L_S(h) + \text{complexity penalty}(h) \right\}

SRM Algorithm: 1. For each n, compute h_n = \text{ERM}_{\mathcal{H}_n}(S) 2. For each n, compute confidence interval: L_S(h_n) \pm \sqrt{\frac{\text{VCdim}(\mathcal{H}_n) + \ln(1/\delta)}{m}} 3. Select n^* that minimizes the upper bound of the confidence interval 4. Return h_{n^*}

Minimum Description Length (MDL)

The MDL principle formalizes Occam’s razor: among hypotheses that fit the data equally well, prefer the simplest one. In MDL, simplicity is measured by description length.

Two-Part MDL: The total description length consists of: 1. Model description length: L(h) - bits needed to describe hypothesis h 2. Data description length: L(S|h) - bits needed to describe data S given h

MDL selects: \hat{h} = \arg\min_h \{L(h) + L(S|h)\}

Normalized Maximum Likelihood (NML): For model class \mathcal{M} and data S: P_{\text{NML}}(S|\mathcal{M}) = \frac{\max_{\theta \in \mathcal{M}} P(S|\theta)}{\sum_{S'} \max_{\theta \in \mathcal{M}} P(S'|\theta)}

The MDL principle is closely related to Bayesian model selection and provides strong theoretical guarantees for model selection.

Consistency and Universal Learning

Definition (Consistency): A learning algorithm is consistent for a hypothesis class \mathcal{H} if for every h^* \in \mathcal{H} and distribution \mathcal{D} such that L_{\mathcal{D}}(h^*) = 0: \lim_{m \to \infty} \mathbb{P}_{S \sim \mathcal{D}^m}[L_{\mathcal{D}}(A(S)) > \epsilon] = 0 for every \epsilon > 0.

Consistency is a weaker requirement than PAC learnability, as it doesn’t provide finite sample guarantees.

Universal Learning: Some algorithms can learn any learnable concept class without knowing the class in advance. The SRM principle with appropriate complexity penalties achieves universal learning.

Multiple Testing and Error Control

In many modern statistical applications, we test multiple hypotheses simultaneously, leading to the multiple testing problem. This is particularly relevant in high-dimensional settings common in machine learning.

For more on this topic, see James et al. (2023, Ch. 13).

The Multiple Testing Problem

When performing m hypothesis tests simultaneously, each at level \alpha, the probability of making at least one Type I error (false positive) can be much larger than \alpha. If tests are independent: \mathbb{P}(\text{at least one false positive}) = 1 - (1-\alpha)^m \approx m\alpha

For m = 1000 and \alpha = 0.05, this probability is approximately 1, making the tests meaningless.

Family-Wise Error Rate (FWER)

The FWER is the probability of making at least one Type I error: \text{FWER} = \mathbb{P}(V \geq 1) where V is the number of false positives.

Bonferroni Correction: Test each hypothesis at level \alpha/m. This controls FWER at level \alpha by the union bound: \text{FWER} \leq \sum_{i=1}^m \mathbb{P}(\text{reject } H_i | H_i \text{ true}) \leq m \cdot \frac{\alpha}{m} = \alpha

Holm’s Method: A step-down procedure that is uniformly more powerful than Bonferroni: 1. Order p-values: p_{(1)} \leq p_{(2)} \leq \cdots \leq p_{(m)} 2. Find largest k such that p_{(k)} \leq \frac{\alpha}{m+1-k} 3. Reject hypotheses H_{(1)}, \ldots, H_{(k)}

False Discovery Rate (FDR)

The FDR is the expected proportion of false positives among rejected hypotheses: \text{FDR} = \mathbb{E}\left[\frac{V}{\max(R, 1)}\right] where R is the total number of rejections.

Benjamini-Hochberg Procedure: Controls FDR at level q: 1. Order p-values: p_{(1)} \leq p_{(2)} \leq \cdots \leq p_{(m)} 2. Find largest k such that p_{(k)} \leq \frac{k}{m} \cdot q 3. Reject hypotheses H_{(1)}, \ldots, H_{(k)}

Theorem (BH Controls FDR): Under independence or positive dependence, the BH procedure controls FDR at level q.

Adaptive FDR Control

When the proportion of true null hypotheses \pi_0 is unknown, adaptive procedures can be more powerful:

Storey’s Method: 1. Estimate \pi_0 using p-values in [\lambda, 1] for some \lambda \in (0,1): \hat{\pi}_0(\lambda) = \frac{\#\{p_i > \lambda\}}{m(1-\lambda)} 2. Apply BH procedure with level q/\hat{\pi}_0(\lambda)

Local FDR and Empirical Bayes

The local FDR is the posterior probability that the null hypothesis is true given the observed test statistic: \text{fdr}(z) = \mathbb{P}(H_0 | Z = z)

Using empirical Bayes methods, we can estimate the local FDR and make more informed decisions about individual hypotheses.

Applications in Machine Learning

Multiple testing corrections are crucial in:

  1. Feature Selection: When testing thousands of features for relevance 2. Model Comparison: When comparing multiple algorithms on multiple datasets 3. Hyperparameter Tuning: When testing many parameter configurations 4. A/B Testing: When running multiple experiments simultaneously

Example (Feature Selection): In genomics, when testing 20,000 genes for association with disease: - Bonferroni: \alpha = 0.05/20000 = 2.5 \times 10^{-6} - BH with FDR = 0.05: Much more powerful while controlling expected false discovery rate

The choice between FWER and FDR control depends on the cost of false positives versus false negatives in the specific application (James et al. 2023).

Representation as Inductive Bias

Inductive bias refers to the set of assumptions a learner uses to make predictions on unseen data. The choice of data representation is one of the most powerful forms of inductive bias, fundamentally shaping what patterns can be learned and how efficiently.

The Role of Representation in Learning

The representation hypothesis states that the success of machine learning algorithms depends critically on the choice of data representation. Different representations can make the same learning problem trivial or intractable.

Example: Consider learning the XOR function: - In the original binary representation: (0,0) \to 0, (0,1) \to 1, (1,0) \to 1, (1,1) \to 0 - This is not linearly separable - With feature transformation \phi(x_1, x_2) = (x_1, x_2, x_1 \oplus x_2): becomes linearly separable

Feature Engineering and Selection

Feature Engineering is the process of using domain knowledge to create features from raw data, explicitly encoding prior beliefs about the data into the learning process.

Common Feature Engineering Techniques: 1. Polynomial features: \phi(x) = (x, x^2, x^3, \ldots) for capturing nonlinear relationships 2. Interaction features: \phi(x_1, x_2) = (x_1, x_2, x_1 x_2) for capturing feature interactions 3. Domain-specific transformations: Log transforms, Fourier transforms, wavelets 4. Binning and discretization: Converting continuous variables to categorical 5. Text features: TF-IDF, n-grams, word embeddings

Feature Selection involves selecting a subset of the most informative features, imposing a bias that the selected features are sufficient for the learning task.

Feature Selection Methods: 1. Filter methods: Select features based on statistical properties (correlation, mutual information) 2. Wrapper methods: Use learning algorithm performance to guide selection 3. Embedded methods: Feature selection integrated into learning algorithm (LASSO, Ridge)

Mathematical Framework: For feature selection with d original features, we seek a subset S \subseteq \{1, 2, \ldots, d\} that minimizes: \hat{S} = \arg\min_{S} \left\{ L(h_S) + \lambda |S| \right\} where h_S is trained using only features in S and \lambda controls the sparsity-accuracy tradeoff.

Representation Learning

Representation learning aims to automatically discover good features from data, reducing the need for manual feature engineering.

Unsupervised Representation Learning

Principal Component Analysis (PCA): Finds linear projections that maximize variance: \mathbf{w}_1 = \arg\max_{\|\mathbf{w}\|=1} \text{Var}(\mathbf{w}^\top \mathbf{X})

Autoencoders

Autoencoders: Learn compressed representations through reconstruction: - Encoder: \mathbf{z} = f_{\text{enc}}(\mathbf{x}; \theta_{\text{enc}}) - Decoder: \hat{\mathbf{x}} = f_{\text{dec}}(\mathbf{z}; \theta_{\text{dec}}) - Objective: \min_{\theta} \mathbb{E}[\|\mathbf{x} - f_{\text{dec}}(f_{\text{enc}}(\mathbf{x}))\|^2]

Variational Autoencoders (VAEs): Learn probabilistic latent representations: \mathcal{L} = \mathbb{E}_{q(\mathbf{z}|\mathbf{x})}[\log p(\mathbf{x}|\mathbf{z})] - D_{KL}(q(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))

Self-Supervised Learning

Contrastive Learning: Learn representations by contrasting positive and negative pairs: \mathcal{L} = -\log \frac{\exp(\text{sim}(\mathbf{z}_i, \mathbf{z}_j)/\tau)}{\sum_{k=1}^{2N} \mathbb{1}_{k \neq i} \exp(\text{sim}(\mathbf{z}_i, \mathbf{z}_k)/\tau)}

Masked Language Modeling: Predict masked tokens in sequences (BERT, GPT)

Rotation Prediction: Predict image rotations as pretext task

Deep Learning and Hierarchical Representations

Deep neural networks learn hierarchical feature representations through multiple layers of nonlinear transformations.

Universal Approximation Theorem: A feedforward network with a single hidden layer can approximate any continuous function on a compact set, given sufficient width.

Depth vs Width

Depth vs. Width: Deep networks can represent certain functions exponentially more efficiently than shallow networks: - Compositional functions: f(x) = f_L \circ f_{L-1} \circ \cdots \circ f_1(x) - Hierarchical features: Low-level → Mid-level → High-level features

Hierarchical Features

Examples of Learned Hierarchies: - Computer Vision: Edges → Textures → Parts → Objects - Natural Language: Characters → Words → Phrases → Sentences → Documents - Speech: Phonemes → Words → Phrases → Sentences

The Manifold Hypothesis

The Hypothesis

The manifold hypothesis posits that high-dimensional data often lies on or near a low-dimensional manifold embedded in the high-dimensional space.

Formal Statement: Real-world data \mathbf{x} \in \mathbb{R}^D lies on or near a d-dimensional manifold \mathcal{M} where d \ll D.

Implications: 1. Dimensionality reduction: Effective low-dimensional representations exist 2. Generalization: Interpolation between data points on the manifold should be meaningful 3. Sample complexity: Learning can be easier in the intrinsic dimension d rather than ambient dimension D

Algorithms

Manifold Learning Algorithms: - Linear: PCA, Factor Analysis - Nonlinear: Isomap, Locally Linear Embedding (LLE), t-SNE, UMAP - Deep: Autoencoders, VAEs, Normalizing Flows

Inductive Biases in Different Domains

Computer Vision - Translation invariance: Convolutional layers - Locality: Local receptive fields - Hierarchy:

Multi-scale feature detection - Data augmentation: Rotation, scaling, cropping invariance

Natural Language Processing - Sequential structure: Recurrent and Transformer architectures - Compositionality:

Hierarchical parsing - Attention mechanisms: Relevant context selection - Positional encoding: Order information

Graph Learning - Permutation invariance: Graph neural networks - Locality: Message passing between neighbors -

Structural patterns: Motifs, communities

Theoretical Perspectives on Representation

Information-Theoretic View: Good representations should: 1. Preserve task-relevant information: I(Y; \phi(X)) \approx I(Y; X) 2. Compress irrelevant information: Minimize I(\phi(X); X) subject to task performance

Geometric View: Representations should: 1. Separate classes: Maximize inter-class distances 2. Cluster similar examples: Minimize intra-class distances 3. Preserve local structure: Maintain neighborhood relationships

Causal View: Representations should capture: 1. Causal factors: Variables that causally influence the target 2. Invariant features: Stable across different environments 3. Disentangled factors: Independent generative factors

Evaluation of Representations

Downstream Task Performance: Measure performance on target tasks using learned representations.

Linear Probing: Train linear classifiers on frozen representations to assess quality.

Clustering Metrics: Evaluate how well representations cluster semantic categories.

Visualization: Use t-SNE, UMAP to visualize representation structure.

Disentanglement Metrics: - Mutual Information Gap (MIG) - Separated Attribute Predictability (SAP) - Disentanglement, Completeness, Informativeness (DCI)

The choice of representation fundamentally determines what can be learned efficiently, making it one of the most important design decisions in machine learning (Shalev-Shwartz and Ben-David 2014; Theodoridis 2026).

Online & Sequential Learning

In contrast to the batch learning setting where the entire training set is available at once, in the online learning model, the learner receives data sequentially, one example at a time. After receiving an example, the learner makes a prediction, receives the true label, and incurs a loss. The goal of the online learner is to minimize its cumulative loss over a sequence of rounds.

The Online Learning Model

In each round t=1, 2, \dots, T:

  1. The learner receives an instance x_t
  2. The learner predicts a label \hat{y}_t
  3. The true label y_t is revealed 4. The learner incurs a loss \ell(\hat{y}_t, y_t)

Model Description

The online learning model is particularly relevant in scenarios where: - Data arrives continuously over time - The underlying distribution may change (concept drift) - Memory and computational resources are limited - Immediate predictions are required

Regret Analysis

The performance of an online learning algorithm is measured by its regret, which compares the cumulative loss of the algorithm to that of the best fixed hypothesis in hindsight:

\text{Regret}_T = \sum_{t=1}^T \ell(\hat{y}_t, y_t) - \min_{h \in \mathcal{H}} \sum_{t=1}^T \ell(h(x_t), y_t)

The goal is to achieve sublinear regret, meaning \text{Regret}_T = o(T), which ensures that the average regret approaches zero as T \to \infty.

Online Convex Optimization

Many online learning problems can be formulated as online convex optimization (OCO) problems. In OCO, at each round t:

  1. The learner chooses a point w_t from a convex set \mathcal{W} 2. A convex loss function f_t: \mathcal{W} \to \mathbb{R} is revealed 3. The learner incurs loss f_t(w_t)

The regret is defined as: \text{Regret}_T = \sum_{t=1}^T f_t(w_t) - \min_{w \in \mathcal{W}} \sum_{t=1}^T f_t(w)

Online Gradient Descent

OGD Algorithm

One of the most fundamental online learning algorithms is Online Gradient Descent (OGD):

w_{t+1} = \Pi_{\mathcal{W}}(w_t - \eta_t \nabla f_t(w_t))

where \Pi_{\mathcal{W}} is the projection onto the constraint set \mathcal{W} and \eta_t is the learning rate.

Theorem (OGD Regret Bound): For convex and Lipschitz loss functions, OGD with learning rate \eta_t = \frac{D}{G\sqrt{t}} achieves regret: \text{Regret}_T \leq DG\sqrt{T} where D is the diameter of \mathcal{W} and G is the Lipschitz constant.

The Perceptron Algorithm

The Perceptron algorithm is a classic example of an online learning algorithm for binary classification. It maintains a weight vector \mathbf{w} and predicts the label of an instance \mathbf{x} based on the sign of \langle\mathbf{w}, \mathbf{x}\rangle.

Algorithm (Perceptron): - Initialize \mathbf{w}_1 = \mathbf{0} - For t = 1, 2, \ldots, T: - Receive \mathbf{x}_t - Predict \hat{y}_t = \text{sign}(\langle\mathbf{w}_t, \mathbf{x}_t\rangle) - Receive y_t - If \hat{y}_t \neq y_t: \mathbf{w}_{t+1} = \mathbf{w}_t + y_t\mathbf{x}_t - Else: \mathbf{w}_{t+1} = \mathbf{w}_t

Theorem (Perceptron Mistake Bound): If the data is linearly separable with margin \gamma > 0 and \|\mathbf{x}_t\| \leq R for all t, then the Perceptron algorithm makes at most \frac{R^2}{\gamma^2} mistakes.

Multiplicative Weights and Hedge Algorithm

Hedge Algorithm

The Hedge algorithm (also known as Multiplicative Weights) is a fundamental online learning algorithm for the expert setting:

Algorithm (Hedge): - Initialize weights w_1^{(i)} = 1 for all experts i \in [N] - For t = 1, 2, \ldots, T: - Choose expert i_t with probability p_t^{(i)} = \frac{w_t^{(i)}}{\sum_{j=1}^N w_t^{(j)}} - Receive losses \ell_t^{(1)}, \ldots, \ell_t^{(N)} - Update weights: w_{t+1}^{(i)} = w_t^{(i)} \exp(-\eta \ell_t^{(i)})

Theorem (Hedge Regret Bound): With learning rate \eta = \sqrt{\frac{\ln N}{T}}, the Hedge algorithm achieves regret: \text{Regret}_T \leq \sqrt{2T \ln N}

Follow the Regularized Leader

FTRL Framework

The Follow the Regularized Leader (FTRL) framework generalizes many online learning algorithms:

w_{t+1} = \arg\min_{w \in \mathcal{W}} \left\{ \sum_{s=1}^t f_s(w) + R(w) \right\}

where R(w) is a regularization function. Different choices of R(w) lead to different algorithms: - R(w) = \frac{1}{2\eta}\|w\|^2 gives Online Gradient Descent - R(w) = \frac{1}{\eta}\sum_i w_i \ln w_i gives Hedge (in the simplex)

Adaptive Learning Rates

Adaptive Methods

Modern online learning algorithms often use adaptive learning rates that adjust based on the observed gradients:

AdaGrad: Uses learning rates inversely proportional to the square root of the sum of squared gradients: \eta_{t,i} = \frac{\alpha}{\sqrt{\sum_{s=1}^t g_{s,i}^2 + \epsilon}}

Online Newton Step: Uses second-order information: w_{t+1} = w_t - H_t^{-1} \nabla f_t(w_t) where H_t = \sum_{s=1}t \nabla^2 f_s(w_s) is the cumulative Hessian.

Bandit Learning

In the multi-armed bandit setting, the learner only observes the loss of the chosen action, not the losses of all possible actions. This partial feedback makes the problem significantly more challenging.

Algorithm (UCB1 for Stochastic Bandits): - For each arm i, maintain empirical mean \hat{\mu}_i and number of pulls n_i

At time t, choose arm: i_t = \arg\max_i \left\{ \hat{\mu}_i + \sqrt{\frac{2\ln t}{n_i}} \right\}

Theorem (UCB1 Regret): For stochastic bandits with K arms, UCB1 achieves regret: \mathbb{E}[\text{Regret}_T] \leq \sum_{i: \Delta_i > 0} \frac{8\ln T}{\Delta_i} + O(K) where \Delta_i is the suboptimality gap of arm i.

Contextual Bandits

In contextual bandits, the learner observes a context x_t before choosing an action. This setting bridges the gap between supervised learning and reinforcement learning.

LinUCB Algorithm: For linear contextual bandits where rewards are linear in features: - Maintain estimate \hat{\theta}_t and confidence set - Choose action with highest upper confidence bound: a_t = \arg\max_a \left\{ \hat{\theta}_t^\top x_{t,a} + \beta_t \sqrt{x_{t,a}^\top A_t^{-1} x_{t,a}} \right\}

Online-to-Batch Conversion

Conversion Guarantees

Online learning algorithms can be converted to batch learning algorithms with strong generalization guarantees:

Theorem (Online-to-Batch Conversion): If an online algorithm achieves regret R_T, then averaging its predictions gives a batch algorithm with generalization error O(R_T/T).

This connection shows that online learnability implies batch learnability, providing another perspective on the fundamental limits of learning (Shalev-Shwartz and Ben-David 2014).
